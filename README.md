# نظام إعداد رسائل إدارة الاستخدام

أداة محلية (صفحة واحدة HTML بدون أي اعتماد على الإنترنت) لإعداد وطباعة رسائل:
- تصريح عمل
- تجديد إذن عمل
- تعاقد من الداخل (فرد / شركة)

## التشغيل مباشرة
افتح ملف `index.html` في أي متصفح — يعمل بدون سيرفر وبدون إنترنت.

## النشر عبر GitHub Pages (رابط دائم تفتحه من أي جهاز)
1. أنشئ مستودع (Repository) جديد على GitHub، مثلاً باسم `molr-letters`.
2. ارفع ملف `index.html` (وملف `README.md` هذا) إلى المستودع.
3. من إعدادات المستودع: **Settings → Pages**.
4. تحت **Source** اختر الفرع `main` والمجلد `/ (root)`، ثم احفظ.
5. بعد دقيقة أو دقيقتين سيظهر رابط بالشكل:
   `https://USERNAME.github.io/molr-letters/`
6. هذا الرابط يفتح الأداة مباشرة من المتصفح، ويعمل بدون إنترنت بعد أول تحميل إذا فعّلت خاصية العمل دون اتصال في المتصفح (اختياري).

بعد النشر، أي موظف يفتح نفس الرابط سيحصل على آخر نسخة من الأداة تلقائياً.
